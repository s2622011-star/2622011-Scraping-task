# 武蔵野大学サイトのサイトマップ抽出

データサイエンスプログラミング I の第3回個人課題。武蔵野大学公式サイトのトップページから同じホスト内のリンクをたどり、各公開HTMLページのURLと `<title>` の文字列をCSVに保存します。

## 実行方法

第4回の授業資料と同様に、`uv` で仮想環境を作り、requestsとBeautiful Soupを入れます。

```sh
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
python scrape.py
```

巡回が終わると `sitemap.csv` ができます。列は `url` と `title` です。HTMLにタイトルがない場合、タイトル欄は空欄になります。

## 巡回の流れ

1. トップページを巡回候補に入れます。取得したHTMLからタイトルとリンクを読み取ります。
2. 相対リンクを絶対URLに変換し、`www.musashino-u.ac.jp` のリンクだけを次の候補にします。ページ内の位置を示す `#` 以下を外し、候補に入れたURLを記録して重複を防ぎます。
3. HTTPリクエストごとに `time.sleep()` で1秒以上待ちます。リダイレクト先も候補に入れる前に対象ホストを確認します。
4. URLをキー、タイトルを値にした辞書からCSVを書き出します。

途中経過はローカルの `.crawl-state.json` に保存します。同じコマンドで再開でき、最初から巡回するには `--state` に別のファイル名を指定します。HTTPエラーなどで取得できなかったURLは、このファイルの `failures` に記録します。動作確認で処理件数を制限するには `--limit 10` を指定します。

コードの作成と確認に生成AIを使用しました。
