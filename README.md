# 武蔵野大学サイトのサイトマップ抽出

武蔵野大学公式サイトのトップページから同じホスト内のリンクをたどり、各ページのURLとタイトルをCSVに保存するPythonプログラムです。同じURLへの再訪問を避け、アクセスの間隔を1秒以上空けます。

## 実行方法

次のコマンドで仮想環境を作り、必要なパッケージ（`requests` と `beautifulsoup4`）をインストールして実行します。

```sh
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
python scrape.py
```

実行が終わると、URLとタイトルを記録した `sitemap.csv` が出力されます。元のページにタイトルがなければ、CSVのタイトル欄は空欄です。途中で止めた場合は、同じコマンドを実行すると続きから再開できます。

## 収集結果

2026年11月11日の実行で2,693ページ分を保存しました。タイトル欄が空の行は43件です。HTTPエラーで取得できなかったURLは131件でした。
